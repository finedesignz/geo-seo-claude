|----------|-------------|
| repo → image build context | files copied into the image; a leaked `.env` would bake a secret |
| image layers → registry/inspector | `docker history`/`inspect` must reveal no secret |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-06-02 | Information disclosure | committed `.env.example` | mitigate | only placeholders/defaults, no real values; verify grep finds no token-shaped value |
| T-06-03 | Elevation of privilege | runtime container | mitigate | non-root `USER bun`; slim base; no `--privileged` |
