  <name>Task 1: deploy-verify smoke script</name>
  <files>scripts/deploy-verify.sh</files>
  <action>
    Per D-08 + RESEARCH §"Deploy-verify smoke" + the confirmed field names in &lt;interfaces&gt;. `#!/usr/bin/env bash`, `set -euo pipefail`. Read from env (fail with clear message if unset): `GEO_API_BASE` (e.g. https://geo-api.titaniumlabs.us), `GEO_API_TOKEN` (a GEO_API_KEYS bearer), `AUDIT_URL` (default https://example.com). NEVER hardcode a token or URL.
    Sequence:
    1. Poll `GET $GEO_API_BASE/healthz` up to ~60s (30 tries × 2s) until HTTP 200; fail if never 200.
    2. Unauth doc probes: `curl -fsS -o /dev/null $GEO_API_BASE/openapi.json` and `.../docs` (rule 21 reachability). 
    3. Negative auth probe: `POST /audit` with NO Authorization header → assert HTTP 401 (bearer enforced). Fail if not 401.
    4. Authed `POST /audit` with `Authorization: Bearer $GEO_API_TOKEN` and body `{"url":"$AUDIT_URL"}` → parse `job_id` from the JSON. Use a robust extractor (prefer `bun -e` JSON.parse on stdin; fall back to grep `\"job_id\"`). Fail if no job_id.
    5. Poll `GET /audit/$job_id` (Bearer) up to ~2min (60×2s): exit 0 on `"status":"done"` (print the body incl score+findings), exit 1 on `"status":"failed"`, exit 1 if it never finishes.
    Keep it dependency-light (curl + bun/grep only). Mark clearly in a header comment that this is run by the verifier AFTER the live Coolify deploy (plan 03), not in CI.
  </action>
