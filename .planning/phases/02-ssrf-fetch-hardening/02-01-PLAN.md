<objective>
The core vertical slice: `createSafeFetcher(options)` that validates scheme/port, resolves the hostname to ALL A/AAAA records, denies the fetch if ANY resolved IP is blocked (SEC-01 post-DNS), and connects to a PINNED validated IP while preserving the original Host header + TLS SNI so the address validated equals the address connected (SEC-02 resolve-then-pin, defeats DNS-rebinding TOCTOU). Returns the `@geo/core` `Fetcher`/`FetchResult` shape, with every failure as a structured error code (SEC-05). No redirects yet (Wave 2), no size cap yet (Wave 3) — happy path + SSRF block only.

Purpose: Lock in the non-negotiable resolve-then-pin guarantee before layering redirects and body handling on top.
Output: A working fetcher that succeeds on a public/loopback test target and blocks every SSRF vector after DNS resolution, with a passing rebinding integration test.
</objective>

|----------|-------------|
| caller → createSafeFetcher | Untrusted URL (scheme/port/userinfo/host) |
| DNS resolution → connect | Attacker-controlled DNS records; TOCTOU window |
| TLS connect | SNI/cert validation when connecting by IP |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-02-06 | Info Disclosure | file:/gopher:/data: scheme abuse | mitigate | scheme allowlist http/https → SSRF_BLOCKED_SCHEME; tests file:/gopher: |
