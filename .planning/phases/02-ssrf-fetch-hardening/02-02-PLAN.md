<objective>
Add the manual redirect-following loop to `createSafeFetcher` (SEC-03): use undici `redirect: 'manual'`, and on every 3xx, resolve the (possibly relative) Location against the current URL and re-run the COMPLETE scheme→port→resolve-then-pin validation before connecting to the next hop — so a redirect pivot from a public host to a private/metadata IP is blocked at the hop, never silently followed (this also extends SEC-02's resolve-then-pin to every hop). Cap at maxRedirects (default 5 → TOO_MANY_REDIRECTS) and record each hop in redirectChain.

Purpose: Auto-follow redirects bypass SSRF validation; the manual loop is the only safe way to re-validate each pivot.
Output: Redirect handling layered onto the Wave 1 fetcher, with integration tests proving pivot-to-private blocks and hop-cap enforcement.
</objective>
