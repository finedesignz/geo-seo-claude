<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller siteUrl → checkRobots | Untrusted URL string; validated via `new URL()` before any fetcher call (V5) |
| fetcher body → regex/line parser | Untrusted robots.txt text parsed line-by-line |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-R1 | DoS | line-by-line robots.txt parser | mitigate | Line-split + bounded per-line slicing; no catastrophic-backtracking regex over the whole body. Caller (Phase 2 fetcher) enforces the size cap — boundary documented. |
| T-01-R2 | Spoofing/Tampering | sitemap URL value | mitigate | Validate every sitemap value with `new URL()`; reject non-absolute/invalid (fixes httphttps corruption). |
| T-01-R3 | (network) SSRF | fetcher | transfer | @geo/core never fetches directly; injected fetcher (Phase 2) owns SSRF. checkRobots only validates the input URL is parseable. |
</threat_model>
