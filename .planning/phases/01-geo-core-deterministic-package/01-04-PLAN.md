    - uniqueness_signals (max 10): original data, case-study/tool mentions.
    Cases:
    - CITABILITY_WEIGHTS values sum to exactly 100 (test asserts).

    - computeCitabilityScore over a multi-block HTML page returns an aggregate 0–100 with a full breakdown of all five keys.
    - Determinism: identical input → identical score (call twice, assert equal).
    - Empty/whitespace HTML → score 0, breakdown all zeros, errors:[] (no throw).
