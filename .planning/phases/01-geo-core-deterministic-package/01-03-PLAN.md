<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| page HTML → JSON-LD regex extractor | Untrusted, possibly adversarial HTML |
| JSON-LD string → JSON.parse | Untrusted JSON payload |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-S1 | DoS | JSON-LD extraction regex on adversarial HTML | mitigate | Bounded lazy match `[\s\S]*?`; input-length guard (max ~5MB) before regex pass. Decompression/oversized handling is the caller's job (Phase 2) — boundary documented. |
| T-01-S2 | Tampering | prototype pollution via JSON-LD `__proto__` | mitigate | JSON.parse is V8-safe; never spread/merge parsed JSON-LD into templates; read via Object.hasOwn. Test asserts Object.prototype untouched. |
| T-01-S3 | Tampering | malformed JSON-LD | mitigate | per-block try/catch, error accumulation, no throw (D-06). |
</threat_model>
