## Trust Boundaries

| Boundary | Description |

| concurrent workers → one job | two workers could race the same job (double-claim / stale completion) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-SSRF | Elevation of privilege | pipeline.ts fetch stage | mitigate | `createSafeFetcher()` (Phase 2) is the only fetch path; `FetchResult.error` short-circuits to `failJob` BEFORE any scoring call — asserted by WORK-02b (scorer call-count 0) |
| T-04-FENCE | Spoofing / Tampering | lease completion | mitigate | all DAL writes fenced by `lease_token`; heartbeat `renewLease`-false aborts in-flight and the catch suppresses `failJob` when `ac.signal.aborted` — asserted by WORK-04a |
| T-04-PARTIAL | Tampering | job result integrity | mitigate | `completeJob` reachable only from the single success line; every catch path → `failJob`; no partial score — asserted by WORK-02b + the scorer suite |
| T-04-DOS | Denial of service | unbounded concurrency | mitigate | in-flight counter caps at `WORKER_CONCURRENCY`; excess waits in the Postgres queue — asserted by WORK-03 |
