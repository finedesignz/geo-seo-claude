## Out of Scope (reasons held at close)
| Feature | Reason |
|---------|--------|
| `claude -p` / agent-host scoring | Score is a structured SDK call |
| Routing deterministic checks through an LLM | Plain `@geo/core` functions; LLM-routing is the waste to prevent |
| Reusing Python scrapers in-process | All-TS; scrapers ported to `@geo/core` |
| Replacing/migrating the Flask CRM | Out of scope this milestone |
| Synchronous `/audit` endpoint | Async job model only |
| WebSocket result streaming | Polling + webhook suffice |
| Multi-tenant billing / Titanium licensing | Internal service for now |
| Admin UI for geo-api | Consumer apps own their UIs |
| GraphQL / gRPC | REST + OpenAPI sufficient |
