## 4. Secret / Safety Posture

- No secrets committed: repo-wide scan for `postgres://`, `sk-ant-`, populated `DATABASE_URL=`/`ANTHROPIC_API_KEY=` in `packages/`+`examples/` (excl. `.env.example`/docs/tests) → **clean**.
- `DATABASE_URL`, `ANTHROPIC_API_KEY`, `GEO_API_KEYS` env-only; `@geo/db` + `@geo/worker` + `@geo/cron` fail-fast on missing env.
- `.dockerignore` excludes every `.env*` then re-includes only `.env.example` — no secret enters build context (DEPLOY-03).
- Tests use PGlite / TEST_DATABASE_URL-gated, never prod.
- SSRF resolve-then-pin at every URL fetch point: audit fetch (`createSafeFetcher`), submit-time callback validation (`validateUrlHost`), webhook fire (`createSafeRequester`, per-attempt re-validation).
